5. JavaScript code defense

Explain initialization, state synchronization, activation, and Escape/focus behavior in your own words. Refer to the exact variable, attribute, dataset value, function, and event used.

Initialization: I used document.documentElement.classList.add("js") to identify that JavaScript is enabled. The button.hidden value (set to false) was used to control the visibility of the menu button and list.dataset.open (set to false) to set the initial menu option to closed.

State synchronization: I used setMenu(open) function to update the aria-expanded attribute and the list.dataset.open value to keep the visual and accessible state consistent.

Activation: I used the click event to see when the menu button is clicked. The setMenu function was used to check the current state and update it accordingly.

Escape/focus behavior: I used the document.addEventListener("keydown", (event) => { ... }) . It checks whether the escape key is pressed, and aria-expanded attribute is true. setMenu(false) is used to close the menu, and button.focus() is used to focus the menu button.
